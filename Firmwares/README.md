## Update über die AirTAK-App

1. Die **Update-Datei** für dein Gerät aufs Handy herunterladen.
2. Funkgerät mit AirTAK verbinden und unter **Einst. → Info → Firmware aktualisieren** die Datei auswählen.
3. Warten, bis das Update fertig ist. Gerät dabei nicht ausschalten.

## Zum ersten Mal installieren

Dafür brauchst du derzeit einen Computer und ein **USB-Kabel, das Daten übertragen kann**.
Nur die Datei herunterzuladen reicht nicht — einen Ein-Klick-Installer gibt es noch nicht.
Die Schritte stehen in der [Installationsanleitung](../docs/firmware-installation.md).
Vorhandene Einstellungen können dabei verloren gehen. ZIP-Dateien nicht entpacken.

**Hinweis:** Das sind Testversionen. Nicht alle Geräte wurden mit dieser Version praktisch getestet.
